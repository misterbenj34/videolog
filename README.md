# VideoLog

A local-first web application designed to help individuals record and manage recurring time capsules (video logs) with structured prompts and guidance.

## Core Concept

- **Recurring Reflections:** Guided prompts at regular intervals to capture personal evolution over time.
- **Local-First Privacy:** Video recordings stay local to your device for complete privacy and ownership.
- **Flexible Storage:** Local storage by default, with optional cloud backup integrations planned for the future.
- **Structured Prompts:** Predefined and customizable questions covering mindset, career, personal projects, and goals.

## Roadmap

- [ ] Core web interface for local recording
- [ ] Predefined question sets & custom questionnaire builder
- [ ] Local storage pipeline & export options
